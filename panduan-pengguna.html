3 Langkah Mudah Menghubungkan Cloud

Ikuti petunjuk praktis ini agar data Anda tersimpan di akun Google Anda sendiri dan dapat dibuka di banyak perangkat sekaligus.

01 dataset

Buat Kunci Cloud Pribadi

Hanya butuh 1 menit lewat akun Google pribadi Anda:

  1. Buka sheets.new di browser.
  2. Klik menu Ekstensi ➔ Apps Script.
  3. Hapus teks lama, tempel kode script di bawah.
  4. Klik Deploy ➔ New Deployment ➔ pilih Web app.
  5. Pilih akses: "Anyone" (Siapa saja).
  6. Salin (*Copy*) Web App URL yang didapat.
02 phone_android

Sambungkan di Perangkat 1 (HP)

Hubungkan aplikasi di HP utama Anda ke Google Sheet tadi:

  1. Buka link aplikasi KEUANGANKU di HP Anda.
  2. Buka menu Setup Database (bawah).
  3. Gulir ke kotak "Koneksi Cloud & Auto-Sync".
  4. Tempel (*Paste*) link Web App URL Anda tadi.
  5. Klik "PAKSA UPLOAD KE CLOUD".

🎉 HP Anda sekarang sudah terhubung aman ke Google Drive pribadi Anda!

check_circle PIN & data aman terisolasi
03 sync

Buka di Perangkat 2 (Laptop/HP Lain)

Agar data di laptop / perangkat kedua Anda langsung sama:

  1. Buka link aplikasi KEUANGANKU di Laptop / HP ke-2.
  2. Buka menu Setup Database.
  3. Tempel (*Paste*) link Web App yang sama persis.
  4. Klik tombol merah: "PAKSA TARIK DARI CLOUD".

⚡ Selesai! Mulai sekarang, setiap kali Anda input data di salah satu perangkat, perangkat lain otomatis ter-update!

verified_user Pertanyaan yang Sering Diajukan (FAQ)

Q: Apakah pemilik link web bisa melihat uang saya?

Sama sekali TIDAK BISA. Aplikasi ini bersifat Client-Side. Data Anda langsung mengalir ke Google Drive Anda sendiri tanpa pernah mampir ke server pengembang.

Q: Berapa banyak HP / Laptop yang bisa dipakai?

Tidak terbatas! Anda bisa membuka aplikasi di 5 HP, 3 laptop, atau tablet seluruh keluarga secara bersamaan dengan link Web App yang sama.

Q: Apakah berbayar atau langganan bulanan?

100% GRATIS selamanya. Sistem memanfaatkan fasilitas Google Apps Script gratis dari akun Google Anda sendiri tanpa biaya server sepeserpun.

Q: Bagaimana jika HP saya hilang atau ganti baru?

Tenang saja! Buka link aplikasi di HP baru, masukkan link Web App Anda, lalu klik "PAKSA TARIK DARI CLOUD". Seluruh data Anda kembali utuh.
