Setup Google Sheets & Apps Script Cloud Sync 100% GRATIS & PRIVAT

Data keuangan Anda tersimpan aman di Google Drive pribadi Anda sendiri tanpa server pihak ketiga

☁️ Cloud Pribadi
table_chart 5.1 Buat Google Spreadsheet Baru
  1. Buka browser di Laptop atau HP, ketik: sheets.new (atau buka Google Drive Anda).
  2. Beri nama spreadsheet, misal: "Database Keuanganku PRO".
  3. Pada menu atas, klik Ekstensi (Extensions) ➔ klik Apps Script.
  4. Tab baru editor skrip Google akan terbuka otomatis.
code 5.2 Tempel Kode Skrip Cloud
  1. Hapus semua baris kode bawaan di editor Apps Script hingga bersih kosong.
  2. Klik tombol SALIN KODE SCRIPT di kotak bawah ini.
  3. Tempelkan (Paste) ke editor Apps Script tersebut.
  4. Tekan ikon Simpan (💾 Simpan Proyek).
rocket_launch 5.3 Terapkan Sebagai Web App
  1. Klik tombol biru Terapkan (Deploy) ➔ pilih Deployment Baru.
  2. Pilih jenis: Aplikasi Web (Web App).
  3. Jalankan sebagai: Saya (email Google Anda).
  4. Siapa yang memiliki akses: Siapa Saja (Anyone).
  5. Klik Terapkan, lalu berikan izin otorisasi Google jika diminta.
link 5.4 Tempel Link di Aplikasi
  1. Salin URL Aplikasi Web yang berakhiran /exec.
  2. Buka aplikasi Keuanganku PRO ➔ menu Setup ➔ Pengaturan.
  3. Cari kolom: "URL Google Apps Script Cloud".
  4. Tempel link tersebut ➔ klik tombol hijau [ SIMPAN & SINKRONKAN ].
Backend Cloud Script Pengguna (Code.gs) 
function doGet(e) {
  var doc = PropertiesService.getScriptProperties();
  var data = doc.getProperty("KEUANGANKU_DATA");
  if (!data) {
    return ContentService.createTextOutput(JSON.stringify({ status: "empty" }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  return ContentService.createTextOutput(data)
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var rawData = e.postData.contents;
    var doc = PropertiesService.getScriptProperties();
    doc.setProperty("KEUANGANKU_DATA", rawData);
    
    // Cadangan fisik ke Cell A1 Spreadsheet Google Anda
    try {
      var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
      sheet.getRange("A1").setValue(rawData);
    } catch(err) {}

    return ContentService.createTextOutput(JSON.stringify({ status: "success", timestamp: new Date() }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Panduan Fitur Keuangan Sehari-hari

Cara mencatat transaksi, mutasi saldo, anggaran budgeting, sinking fund, dan kelola utang

💼 Manajemen Kas
add_circle 1. Catat Transaksi Cepat

Klik menu Transaksi (+). Pilih Pengeluaran atau Pemasukan. Masukkan nominal, pilih dompet/rekening asal, dan kategori. Anda juga bisa melampirkan foto nota/struk belanja!

Saldo rekening otomatis terupdate
sync_alt 2. Transfer / Mutasi Antar Akun

Untuk tarik tunai ATM (Bank ➔ Cash) atau Top-Up E-Wallet (Bank ➔ Dana/Gopay), gunakan tipe Transfer Antar Akun. Saldo berpindah dengan presisi tanpa merusak hitungan grafik pengeluaran!

Bebas salah hitung pengeluaran
pie_chart 3. Batas Anggaran (Budget)

Di menu Setup, tetapkan batas budget per kategori (Makan, Bensin, Belanja). Di Dashboard, pantau indikator warna: hijau (aman), kuning (waspada), dan merah (melebihi batas anggaran).

Mencegah bocor halus finansial
savings 4. Sinking Fund & Impian

Alokasikan dana untuk pos terencana (Qurban, Pajak Kendaraan, Rencana Nikah, atau DP Rumah) lengkap dengan target batas waktu dan persentase tabungan.

Target terukur dan terarah
receipt_long 5. Cicilan & Tagihan

Catat pinjaman atau tagihan cicilan dengan nominal angsuran bulanan. Saat mencatat pembayaran cicilan, sisa utang otomatis berkurang hingga lunas.

Riwayat pelunasan tercatat rapi
save_as 6. Cadangan Manual (.json)

Di menu Setup ➔ Cadangan Manual: Klik Download File Cadangan (.json) untuk menyimpan backup fisik ke komputer. Dapat dipulihkan kapan saja secara offline!

Aman 100% tanpa internet

Manajemen Perangkat & Pemecahan Masalah (FAQ)

Cabut akses jika HP hilang / ganti baru, dan panduan kendala umum

🛡️ Remote Control
phonelink_erase Cabut Akses Perangkat Tertentu

Di menu Setup ➔ Daftar Perangkat Terhubung, Anda bisa melihat seluruh HP & Laptop yang sedang aktif. Jika salah satu HP Anda hilang atau dijual:

  1. Klik tombol merah "Keluarkan" di samping perangkat tersebut.
  2. Akses perangkat tersebut seketika dicabut dan kuota lisensi Anda langsung bebas kembali!
help_center Pemecahan Masalah Cepat (Troubleshooting)

• Data di perangkat baru belum muncul? Buka menu Setup ➔ klik tombol "PAKSA TARIK DARI CLOUD".

• Koneksi Cloud bertuliskan "Koneksi Terganggu"? Pastikan saat deploy Apps Script Anda memilih "Who has access: Anyone (Siapa saja)".

• Lupa PIN Pribadi? Hubungi tim pengembang via email resmi kami di keuangankupro@gmail.com dengan melampirkan bukti pemesanan Anda.

• Versi Aplikasi Saat Ini? Saat ini aplikasi berada dalam fase uji coba resmi v0.1 dan akan ditingkatkan ke v1.0 saat peluncuran publik tanpa menghapus data Anda.
