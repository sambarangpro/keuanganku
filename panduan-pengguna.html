table_chart 5.1 Buat Google Sheet & Buka Script sheets.new
  1. Buka browser, ketik alamat: sheets.new (atau buka Google Drive ➔ Buat Spreadsheet Baru).
  2. Beri nama spreadsheet Anda, misal: "Database Keuanganku PRO".
  3. Pada bilah menu atas, klik Ekstensi (Extensions) ➔ klik Apps Script.
  4. Tab baru editor skrip Google akan terbuka otomatis.
code 5.2 Tempel Kode Skrip Cloud Salin Kode
  1. Di editor Apps Script, hapus semua tulisan kode bawaan (myFunction).
  2. Salin kode skrip resmi di bawah dengan menekan tombol ungu "Salin Kode Script (1-Klik)".
  3. Tempelkan (*paste*) kode tersebut ke editor skrip.
  4. Klik ikon Disket Simpan (Save) save.
cloud_upload 5.3 Deploy Sebagai Web App KRUSIAL
  1. Klik tombol biru Terapkan (Deploy) di pojok kanan atas ➔ Penerapan baru (New deployment).
  2. Klik ikon Roda Gigi ⚙️ di samping kiri ➔ pilih jenis Aplikasi Web (Web app).
  3. Atur 2 pilihan ini dengan benar:
    • Jalankan sebagai (*Execute as*): Saya (Me / Email Anda)
    • Siapa yang memiliki akses (*Who has access*): Siapa saja (Anyone) *(WAJIB!)*
  4. Klik tombol Terapkan (Deploy).
link 5.4 Beri Izin & Salin Web App URL Tahap Akhir
  1. Jika muncul kotak otorisasi: Klik Beri akses (Authorize access) ➔ Pilih akun Google Anda.
  2. Klik tulisan kecil: Lanjutan (Advanced) ➔ Klik Buka Project (tidak aman) ➔ Klik Izinkan (Allow).
  3. Salin (*Copy*) URL Aplikasi Web (Web App URL) yang berakhiran /exec.
  4. Buka aplikasi KEUANGANKU ➔ Menu Setup ➔ Tempel link di "Koneksi Cloud" ➔ Klik "PAKSA UPLOAD KE CLOUD"!
terminal Kode Google Apps Script Cloud Sync (Resmi v1.0) 
function doGet(e) {
  var doc = PropertiesService.getScriptProperties();
  var data = doc.getProperty("KEUANGANKU_DATA");
  if (!data) {
    return ContentService.createTextOutput(JSON.stringify({ status: "empty" }))
      .setMimeType(ContentService.MimeType.JSON);
  }
  return ContentService.createTextOutput(data)
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    var rawData = e.postData.contents;
    var doc = PropertiesService.getScriptProperties();
    doc.setProperty("KEUANGANKU_DATA", rawData);
    
    // Cadangan fisik ke Cell A1 Spreadsheet Google Anda
    try {
      var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
      sheet.getRange("A1").setValue(rawData);
    } catch(err) {}

    return ContentService.createTextOutput(JSON.stringify({ status: "success", timestamp: new Date() }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Buka di Laptop kantor, Tablet, atau HP kedua secara instan tanpa perlu ketik link Cloud lagi!

🔄 Auto-Database Sync
devices METODE 1: Mirip WhatsApp Web (PC/Laptop Baru Tampilkan Barcode) Paling Cepat
  1. Di Laptop / PC / iPad Baru: Buka link https://sambarangpro.github.io/keuanganku/. Di layar pembuka akan langsung muncul Barcode Sesi WhatsApp Web Style.
  2. Di HP Utama Anda: Buka menu Setup ➔ cari bagian Daftar Perangkat Terhubung ➔ klik tombol gradasi "Tautkan Perangkat (Scan QR di PC / iPad)".
  3. Arahkan kamera HP utama Anda ke barcode di layar PC/Laptop ➔ konfirmasi "Ya / Izinkan".
  4. 👉 Selesai! Seketika layar PC Anda otomatis masuk, login terverifikasi, dan seluruh database transaksi Google Sheets langsung ditarik otomatis!
qr_code_2 METODE 2: Scan Barcode Lisensi dari HP Utama
  1. Di HP Utama: Masuk menu Setup ➔ klik "Hubungkan Perangkat Baru (Barcode)".
  2. Di HP Kedua: Buka kamera bawaan HP, Google Lens, atau buka link aplikasi lalu klik Scan Barcode.
  3. Arahkan ke barcode di HP utama. Sistem otomatis login dan mengunduh seluruh transaksi ke HP kedua!

upload_file METODE 3: Solusi Tanpa Webcam / Kamera Buram

Jika laptop Anda tidak memiliki webcam, klik "Download Gambar Barcode" di layar PC, kirim fotonya ke HP Anda, lalu di HP Utama klik "Upload Foto Barcode". Perangkat akan langsung terhubung instan!

Panduan Menggunakan Fitur Keuangan Sehari-hari

Cara mencatat transaksi, transfer saldo, budgeting, sinking fund, dan kelola utang

💼 Manajemen Kas
add_circle 1. Catat Transaksi Cepat

Klik menu Transaksi (+). Pilih Pengeluaran atau Pemasukan. Masukkan nama transaksi, nominal (otomatis ribuan Rupiah), pilih rekening/dompet asal, dan kategori. Anda juga bisa melampirkan foto nota/struk belanja!

Saldo rekening otomatis terupdate
sync_alt 2. Transfer / Mutasi Saldo

Untuk tarik tunai ATM (BSI ➔ Cash) atau Top-Up E-Wallet (BSI ➔ Dana/Gopay), pilih tipe Transfer Antar Akun. Saldo berpindah dengan presisi tanpa merusak hitungan grafik pengeluaran bulanan Anda!

Bebas salah hitung pengeluaran
pie_chart 3. Anggaran Bulanan (Budget)

Di menu Setup, tetapkan batas budget per kategori (Makan, Bensin, Internet, Belanja). Di Dashboard, pantau progress bar indikator: hijau (aman), kuning (waspada), dan merah (melebihi batas anggaran).

Mencegah bocor halus finansial
savings 4. Sinking Fund & Impian

Alokasikan dana untuk pos pengeluaran terencana besar (misal: Qurban tahunan, Pajak Kendaraan bermotor, Rencana Nikah, atau DP Rumah) lengkap dengan tanggal deadline dan persentase pencapaian.

Target terukur dan terarah
receipt_long 5. Cicilan & Utang Piutang

Catat pinjaman atau tagihan cicilan motor/elektronik dengan nominal angsuran rutin per bulan. Setiap kali Anda mencatat pembayaran cicilan, sisa utang akan otomatis berkurang hingga lunas.

Riwayat pelunasan tercatat rapi
save_as 6. Cadangan Manual (.json)

Di menu Setup ➔ Cadangan Manual: Klik Download File Cadangan (.json) untuk menyimpan file backup ke flashdisk. Jika ganti HP offline, cukup klik Pulihkan Data dan pilih file tersebut!

Aman 100% tanpa internet

Manajemen Perangkat Terhubung & Keamanan Jarak Jauh

Cabut akses jika HP hilang, ganti laptop, atau kuota perangkat lisensi penuh

🛡️ Remote Logout
phonelink_erase Cabut Akses Perangkat Tertentu

Di menu Setup ➔ Daftar Perangkat Terhubung, Anda bisa melihat perangkat mana saja yang sedang aktif. Jika salah satu HP Anda hilang atau dijual:

  1. Klik tombol merah "Keluarkan" di samping nama perangkat yang ingin dicabut.
  2. Akan muncul jendela pop-up konfirmasi: "Apakah Anda yakin ingin mengeluarkan perangkat ini?".
  3. Klik Ya, Keluarkan ➔ Seketika akses perangkat tersebut dicabut dan slot kuota lisensi Anda langsung bebas kembali!
help_center Pemecahan Masalah Cepat (Troubleshooting)

• Data di perangkat baru masih kosong? Buka menu Setup ➔ klik tombol merah "PAKSA TARIK DARI CLOUD". Seketika data Google Sheets akan terunduh.

• Ikon di taskbar laptop masih logo lama? Copot (*uninstall*) aplikasi KeuanganKu lama dari laptop ➔ buka kembali di browser ➔ klik Instal kembali agar Windows mengambil logo Biru Muda yang baru.

• Koneksi Cloud bertuliskan "Koneksi Terganggu"? Pastikan saat deploy Apps Script Anda memilih "Who has access: Anyone (Siapa saja)".

lightbulb Ringkasan & Tips Penting

🔑 Token vs PIN Pribadi

Token awal hanya berfungsi sebagai kunci masuk perdana. Setelah PIN Pribadi dibuat, Token awal otomatis hangus sehingga aman jika pesan WA dibaca orang lain.

🔒 Akses Google Apps Script

Wajib memilih "Anyone (Siapa saja)" saat Deploy Web App agar aplikasi di HP/Laptop dapat mengirim dan menarik data tanpa meminta login akun Google berulang kali.

🔄 Auto-Sync Otomatis

Data otomatis tersinkronisasi saat aplikasi dibuka, saat berpindah menu, beralih tab HP, atau setelah menginput transaksi baru di perangkat lain.
