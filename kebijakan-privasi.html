Kebijakan Privasi KEUANGANKU PRO

Berlaku sejak: [PERLU DIISI: tanggal berlaku] · Terakhir diperbarui: 16 November 2026

Ringkasnya:
  • Data keuangan Anda tidak disimpan di server kami. Data itu tersimpan di perangkat Anda dan di akun Google Anda sendiri (Google Drive / Google Sheets / Apps Script milik Anda).
  • Kami hanya menyimpan data yang diperlukan untuk pemesanan dan lisensi, seperti nama, nomor WhatsApp, email, dan daftar perangkat.
  • Kami tidak menjual data Anda dan tidak memakainya untuk iklan.

2. Data yang kami kumpulkan

a. Saat Anda memesan lisensi

  • Nama, nomor WhatsApp, dan alamat email.
  • Paket yang dipilih, harga, metode pembayaran, kode voucher, dan catatan pesanan.
  • Foto bukti transfer (jika Anda mengunggahnya).

b. Saat Anda mengaktifkan dan memakai lisensi

  • Kode token lisensi dan status lisensi.
  • ID perangkat (kode acak yang dibuat aplikasi), jenis perangkat (misalnya "iPhone" atau "Laptop Windows"), serta waktu aktivasi dan waktu terakhir aktif.
  • PIN pribadi lisensi Anda, untuk menautkan perangkat baru.
  • Alamat email akun Google yang Anda tautkan ke lisensi (jika memakai "Masuk dengan Google").
  • ID file Google Sheets database Anda di Google Drive (bukan isinya).
  • Alamat Cloud Script beserta kunci sinkronisasinya (jika Anda memakai fitur Cloud Script). Lihat catatan penting di bagian 3.
  • Catatan aktivitas (log), misalnya waktu login, perangkat yang ditambah atau dilepas, dan percobaan PIN yang salah. Log ini dipakai untuk keamanan dan bantuan teknis.

c. Data keuangan Anda

Rekening, saldo, transaksi, anggaran, utang/piutang, aset, foto struk, dan data keuangan lain yang Anda catat tidak dikirim ke server kami. Data itu tersimpan di:

  • Perangkat Anda (penyimpanan browser/aplikasi). Data ini hilang jika Anda menghapus data browser, kecuali sudah dicadangkan.
  • Google Drive / Google Sheets milik Anda (file "Database Keuanganku PRO"), jika Anda masuk dengan Google.
  • Google Apps Script milik Anda sendiri ("Cloud Script"), jika Anda memasangnya untuk sinkronisasi antar-perangkat.

3. Catatan penting tentang Cloud Script

Supaya perangkat Anda yang lain bisa ikut sinkron secara otomatis, alamat Cloud Script Anda beserta kunci sinkronisasinya disimpan di server lisensi kami. Artinya, secara teknis pengelola server lisensi dapat membuka data di Cloud Script Anda.

Kami berkomitmen tidak membuka data keuangan Anda, kecuali atas permintaan Anda sendiri untuk bantuan teknis. Jika tidak ingin data ini tersimpan, gunakan sinkronisasi lewat Google Drive saja dan jangan aktifkan Cloud Script.

  • Data Google Anda hanya dipakai untuk menjalankan fitur Aplikasi yang Anda gunakan.
  • Data Google Anda tidak dijual, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI.
  • Data Google Anda tidak dibaca manusia, kecuali dengan persetujuan Anda (misalnya saat meminta bantuan teknis), untuk keamanan, atau karena diwajibkan hukum.

5. Untuk apa data dipakai

  • Memproses pesanan, memverifikasi pembayaran, serta mengirim token lisensi lewat email atau WhatsApp.
  • Mengaktifkan lisensi, membatasi jumlah perangkat sesuai paket, dan mencegah penyalahgunaan.
  • Menyinkronkan data antar-perangkat Anda.
  • Memberi bantuan teknis saat Anda menghubungi kami.
  • Menjaga keamanan, misalnya mendeteksi percobaan PIN yang salah berulang kali.

8. Keamanan

  • Semua komunikasi memakai HTTPS.
  • Cloud Script versi 3.0 hanya bisa diakses dengan kunci sinkronisasi milik Anda.
  • Perangkat baru hanya bisa ditambahkan dengan PIN yang benar, lewat Scan QR dari perangkat yang sudah terdaftar, atau dengan akun Google yang terverifikasi. Percobaan PIN yang salah berulang kali akan dikunci sementara.
  • PIN pribadi disimpan di Google Sheet milik pengelola yang tidak dibagikan ke publik.
  • Foto bukti transfer disimpan di Google Drive pengelola dan bisa dibuka oleh siapa pun yang memegang tautannya. Tautan ini tidak dipublikasikan.

Tidak ada sistem yang 100% aman. Jagalah PIN dan token lisensi Anda, dan jangan bagikan kode Cloud Script Anda ke siapa pun.
