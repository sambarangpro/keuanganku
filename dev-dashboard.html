Panduan Setup Master Backend (Gratis 100%)

info

Anda hanya perlu menyiapkan 1 Google Spreadsheet pribadi di Google Drive Anda sebagai database pusat lisensi. Sistem ini sepenuhnya gratis tanpa biaya server!

  1. Buka Google Spreadsheet Baru di browser Anda, beri nama: Database Lisensi Keuanganku PRO.
  2. Klik menu Ekstensi (Extensions) > Apps Script.
  3. Hapus semua kode bawaan, lalu salin seluruh kode dari file master-backend-gas.js:
  4. Pada baris var MASTER_ADMIN_PASSWORD = "...";, pastikan Anda mengingat password rahasia Anda.
  5. Klik tombol Terapkan (Deploy) di pojok kanan atas > Kelola Penerapan Baru (New Deployment).
  6. Pilih jenis ikon roda gigi > Aplikasi Web (Web App).
  7. Atur konfigurasi berikut (Sangat Penting):
    • Jalankan sebagai: Saya (email Anda)
    • Siapa yang memiliki akses: Siapa saja (Anyone)
  8. Klik Terapkan (Deploy), berikan izin Google (Pilih Lanjutan > Buka Project (tidak aman)), lalu salin URL Web App yang berakhiran /exec.
  9. Tempelkan link tersebut ke form login Developer Dashboard ini!

Pasang Aplikasi Developer Portal

Instal sebagai aplikasi mandiri di PC, Laptop, atau HP

Ya, tentu bisa! Developer Portal ini dirancang dengan teknologi PWA (Progressive Web App). Anda dapat menginstalnya di HP maupun Komputer sehingga memiliki ikon aplikasi sendiri di desktop / layar utama dan dapat dibuka tanpa membuka browser terlebih dahulu.

laptop_windows Cara Pasang di Laptop / PC (Windows & Mac)
  1. Buka halaman ini di browser Google Chrome atau Microsoft Edge.
  2. Perhatikan bilah alamat (URL bar) di atas, klik ikon Instal (ikon monitor komputer kecil bertuliskan "Aplikasi tersedia" atau tanda panah ke bawah).
  3. Atau klik menu titik tiga (⋮) di pojok kanan atas browser > pilih "Instal Keuanganku PRO - Dev Portal" (atau Apps > Install this site as an app).
  4. Aplikasi akan langsung terpasang di desktop / menu Start Windows Anda dan berjalan di jendela aplikasi mandiri!
phone_android Cara Pasang di HP Android
  1. Buka halaman developer ini di Google Chrome di HP Anda.
  2. Ketuk menu titik tiga (⋮) di pojok kanan atas Chrome.
  3. Pilih opsi "Instal Aplikasi" atau "Tambahkan ke Layar Utama" (Add to Home Screen).
  4. Ikon Dev Portal akan langsung muncul di layar HP Anda layaknya aplikasi native!
phone_iphone Cara Pasang di iPhone / iPad
  1. Buka halaman ini di browser Safari.
  2. Ketuk tombol Bagikan (Share) (ikon kotak dengan tanda panah ke atas di bilah bawah).
  3. Gulir ke bawah dan ketuk "Tambahkan ke Layar Utama" (Add to Home Screen).
